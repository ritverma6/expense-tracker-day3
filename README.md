# Personal Expense Tracker

## Day 3 - Add Expense from Console

Day 3 adds interactive console input.

The user can enter:
- Expense amount
- Category
- Description

The application creates an `Expense` object using the entered information and today's date.

## Run

```bash
javac -d out src/main/java/com/expense/model/Expense.java src/main/java/com/expense/Main.java
java -cp out com.expense.Main
```
